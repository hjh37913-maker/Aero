# Aero Theme Studio 2.0

## Що нового

- Розширена модель теми (версія 2) з додатковими кольорами, геометрією, типографікою та ефектами
- Живий preview у Theme Studio (картка, текст, кнопка)
- Редагування кольорів через HEX
- Повзунки: скруглення, прозорість скла, глибина
- Дублювання, перейменування, захист пресетів
- Експорт/імпорт JSON з перевіркою
- Безпечні діапазони значень
- Сумісність зі старими темами (Gson ігнорує відсутні поля)
- Краще застосування теми в MainActivity

## Сумісність

- minSdk 31, targetSdk 34
- Ті самі залежності (без нових бібліотек)
- Працює в AIDE
- Старі збережені теми не ламаються

## Перевірка

1. Відкрий Theme Studio.
2. Обери пресет → Дублювати.
3. Зміни кольори, повзунки — preview оновлюється.
4. Застосувати і зберегти.
5. Повернись на головний екран — тема застосована.
6. Перезапусти додаток.
