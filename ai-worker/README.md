# AI WORKER · исследовательский рабочий стол

Локальный прототип для изучения публичных объявлений, а **не автономный заработок и не действующий фриланс-агент**. Срез выполнен 21.11.2026: 20 разных страниц, 7 из них при прямой проверке показывали открытый приём; для 13 других текущий приём не удалось подтвердить, а содержание и суммы частично основаны на поисковом индексе. Устаревший срез не обновляется сам. Источники, статусы, сроки и риски: [ОБЗОР-20.md](ОБЗОР-20.md).

## Доступ и ограничения

- Рейтинг показывает **учебный интерес, не допуск и не вероятность получения заказа**. Freelancehunt пишет, что работать на платформе можно [с 18 лет](https://freelancehunt.com/blog/yak-navchyty-ditei-zarobliaty-online/); [условия Projects.co.id](https://projects.co.id/public/pages/syarat_layanan), §2.1, допускают индивидуальных пользователей старше 17 лет. Для лица младше этих пределов ни одно объявление в подборке не подтверждено как доступное. Не использовать чужой аккаунт или вымышленные данные.
- [Условия Arena](https://help.arena.ai/articles/5629909088-terms-of-use), в частности §§3.5(G) и 5, содержат ограничения коммерческой деятельности, передачи и использования Output. Также важно уточнить возрастной допуск по условиям и [политике конфиденциальности](https://help.arena.ai/articles/3765052346-privacy-policy). Попросите родителя/опекуна выяснить у Arena применимые условия и права; до разъяснения не продавать и не передавать клиентам созданные здесь результаты. Договор, законное участие, право на ИИ, материалы и способ оплаты требуют отдельной проверки. Это не юридическая консультация.
- Отправленных **в рамках этой работы** заявок — 0, полученных заказов — 0, дохода — 0. Ни контактов, ни оплаты, ни клиентских файлов здесь нет. Учебный XLSX не является работой для заказчика; все его записи и коды вымышлены.

## Запуск

Откройте `index.html` в современном браузере: клиентские данные упакованы в `data/bundle.js`, поэтому сервер и интернет для интерфейса не нужны. Ссылки на внешние источники откроются в сети только по явному нажатию.

При необходимости локального сервера из папки `ai-worker`:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000`. Для удалённого/проксируемого preview серверу может потребоваться `--bind 0.0.0.0`; не публикуйте частные данные через такой сервер. **Не загружайте настоящие данные людей или заказчиков.** Никакие внешние поисковые API, ИИ, почта, аккаунты площадок, хранилища и платежи не подключены. Нет фонового мониторинга, регистрации, отправки предложений или выдачи результата клиенту.

## Шесть модулей

1. **Поиск:** локальный поиск и фильтрация 20 сохранённых карточек, а не автоматический сбор новых объявлений.
2. **Оценка:** воспроизводимый топ-5; четыре вручную заданных балла 0–25 — ясность брифа, учебная выполнимость, проверяемость и ясность экономики. Сумма 0–100, равенство разрешается по ID. Субъективно; высокая оценка не отменяет обязательных разрешений.
3. **Разбор:** бюджет, сроки, объём, риск, степень подтверждения, ссылка на первоисточник и ручной чек-лист. Отправка отключена.
4. **Практика:** интерактивная модель на вымышленных данных и один самостоятельный XLSX на общую тему учёта брака; пример не содержит клиентского ТЗ или вложений. Изменения на странице **не меняют** XLSX. Вкладка «Начало» в файле описывает заполнение и пределы (100 условных кодов, 1 000 строк). Проверки ввода можно обойти вставкой; сверка итогов не обнаруживает всех ошибок. Экранная модель ограничена 200 записями за сеанс.
5. **Проверка:** ручной чек-лист и фактическая программная проверка эталонных вычислений модели JavaScript, не проверка редактора Excel. Галочки — заметки, не разрешения.
6. **Контроль:** фактические нулевые результаты этой работы, границы и ссылки на правила. Очистка удаляет лишь два ключа этого приложения из браузера.

Выбранный ID объявления и галочки хранятся в `localStorage` **только если он доступен**; учебные записи на странице живут в памяти до перезагрузки. Не вводите личные или конфиденциальные сведения. Статическая страница не отправляет фоновые сетевые запросы, но размещение через любой внешний сервер само по себе отдаёт ему запросы на файлы.

## Данные и проверка

`data/opportunities.json` — первичная выборка с короткими пересказами; без имён заказчиков, сообщений и вложений. На Freelancehunt счётчик виден на странице, а детали, бюджет и сроки в основном из поисковых фрагментов и могут устареть. Для Projects.co.id срок `Select Deadline` — выбор исполнителя (WIB, UTC+7), `Finish Days` — время выполнения. Указанные бюджеты и комиссия 12% не являются заработком; у значений USD возможна конвертация площадки.

Сборка офлайн-данных и отчёта стандартным Python:

```sh
python3 tools/build-data.py
```

Основные проверки (Python 3 и Node.js без сторонних зависимостей):

```sh
node tests/core.test.cjs
python3 tests/data.test.py
python3 tests/demo.test.py
```

`tests/demo.test.py` проверяет структуру XLSX, ограничения, формулы и их сохранённые результаты по независимому подсчёту. Он **не выполняет** пересчёт в Excel. Если установлены `xlsx`, `xlsx-calc` и `@formulajs/formulajs`, дополнительный тест `node tests/demo-recalc.test.cjs` изменяет входы в памяти и пересчитывает формулы библиотекой (с адаптером дат для её ограничений). Это также не заменяет проверку в Excel, LibreOffice или Google Sheets. Сборка XLSX из `demo/seed.json`: `python3 tools/build-demo.py`; нужен пакет XlsxWriter. Готовый `demo/Учебный-учёт.xlsx` уже включён.

Браузерный тест `tests/browser.test.cjs` требует `playwright-core` и установленного Chromium. Переменные `BASE_URL` и `CHROMIUM_PATH` позволяют указать сервер и браузер. Он проверяет все разделы, фильтры, временную модель, сохранение отметок, загрузку XLSX, прямое открытие `file://` и отсутствие фоновых внешних запросов. Пакеты разработки не включены в репозиторий. Пример установки вне проекта и запуска необязательных тестов (нужны сетевой доступ к npm и необходимые системные библиотеки Chromium):

```sh
npm install --prefix /tmp/ai-worker-tests --no-save --no-package-lock --ignore-scripts \
  xlsx@0.18.5 xlsx-calc@0.9.2 @formulajs/formulajs@4.4.2 \
  playwright-core@1.49.1 @sparticuz/chromium@131.0.1
NODE_PATH=/tmp/ai-worker-tests/node_modules node tests/demo-recalc.test.cjs
# Сначала запустите локальный сервер из раздела «Запуск».
NODE_PATH=/tmp/ai-worker-tests/node_modules node tests/browser.test.cjs
```

Для пересборки XLSX можно установить `XlsxWriter==3.3.3` в отдельное виртуальное окружение Python. В зависимости от системы Chromium может требовать дополнительные библиотеки; на мобильных устройствах, в Safari и в табличных редакторах реальные проверки не проводились.
