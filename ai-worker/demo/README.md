# Один учебный пример

`Учебный-учёт.xlsx` — самостоятельная модель на вымышленных данных для изучения таблиц; это **не** выполненный заказ и не клиентские данные. Основа — `seed.json`, который также используется в отдельной интерактивной модели на странице. Изменения в браузере не изменяют XLSX и наоборот.

На листе «Данные» доступны 1 000 строк, справочник содержит 100 условных кодов и шесть причин. На листе «Сводка» выберите дату месяца в жёлтой ячейке B4. Итог данных сверяется с матрицей по кодам и категориям. Исходные значения: ноябрь 2026 — 18 единиц, декабрь — 3. Разница 0 не гарантирует корректности всех строк: неверная дата, вставка поверх проверки, отсутствие числа или компенсирующие ошибки могут остаться незамеченными. Все данные нужно проверять вручную.

Файл и его формулы проверены программно; пересчёт и внешний вид в конкретных версиях Excel, LibreOffice и Google Sheets пока не проверены. Не использовать или передавать коммерчески до разрешения применимых вопросов прав и условий сервиса.

Генератор `tools/build-demo.py` использует Python и XlsxWriter 3.3.3; исходные данные — `seed.json`. При той же версии библиотеки файл воспроизводится побайтово. Проверки описаны в основном README.
